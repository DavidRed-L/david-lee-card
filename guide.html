3電子郵件

改成（範例）

mailto:你的信箱@gmail.com

⚠️ 前面的 mailto: 要留著，不然點了不會開信件。

✏️ 在 GitHub 網頁上修改（不用裝任何東西）

  1. 1
    打開 index.html 檔案頁面。需要有修改權限的 GitHub 帳號（請 Bear 把你加為協作者，或請 Bear 幫你改）。
  2. 2
    點右上角的 鉛筆圖示 ✏️（Edit this file）。
  3. 3
    按 Ctrl + F，貼上上面紅色的「現在」網址，找到它。
  4. 4
    把它換成你自己的網址（綠色那種格式）。
  5. 5
    點綠色的 Commit changes… → 再按一次 Commit changes。
  6. 6
    等 1～2 分鐘，重新整理名片網頁，點點看新連結 ✅

📷 加上大頭照（選用）

  • 準備一張正方形照片，檔名改成 profile.jpg（全小寫）。
  • 到 專案首頁 → Add file → Upload files → 拖進照片 → Commit changes。
  • 上傳後圓框會自動顯示照片，取代「李」字。

🚫 小提醒

  • 只改引號 "…" 裡面的網址，引號本身要留著。
  • 不要刪掉 <a、<text 這些標籤。
  • 改壞了也沒關係：GitHub 會保留每一次的版本，可以請 Bear 還原。
